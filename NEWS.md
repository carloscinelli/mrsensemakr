# mrsensemakr 0.3.0

* Initial CRAN submission.
* Implements sensitivity analysis for Mendelian Randomization studies.
* Provides `mr_sensemakr()` for computing robustness values, partial R-squared
  measures, and bias-adjusted estimates for instrumental variable regressions.
* Includes sensitivity contour plots via `plot.mr_sensemakr()`.
* Ships with simulated dataset `sim_data` for examples.
